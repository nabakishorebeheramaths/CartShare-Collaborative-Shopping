# Final portal checklist

- [ ] Replace `BatchID` in the repository name with your actual batch ID.
- [ ] Upload the complete folder to GitHub (keep `index.html`, `css/`, and `js/` together).
- [ ] Deploy the static site on GitHub Pages, Netlify or Vercel.
- [ ] Open the deployed URL on a phone and desktop.
- [ ] Test add, quantity update, remove, refresh, activity log and print receipt.
- [ ] Open the deployed URL in two tabs of the same browser and verify tab synchronization.
- [ ] Capture actual screenshots of all four views from the deployed website.
- [ ] Record a 2–5 minute demo video using `VIDEO_DEMO_SCRIPT.md`.
- [ ] Submit the deployed URL + GitHub repository URL + project ZIP + PDF report + demo video.

**Note:** The project and supporting PDF are both required by the portal. The PDF report is included. The actual live URL, screenshots from your deployed instance and recorded video must be created after you deploy and test the project.
