# CartShare — 2–3 minute demo video script

**0:00–0:15 | Introduction**  
“Hello, this is CartShare, a collaborative shopping ecosystem designed for students, roommates and teams. It solves the problem of scattered shopping lists, duplicate purchases and unclear expense tracking.”

**0:15–0:40 | Overview**  
“On the overview page, we can see the number of items, estimated total, contributors and the room code. The room code can be copied and shared with participants.”

**0:40–1:20 | Shared cart**  
“Here I can add an item with quantity and price. The item appears in the shared cart with the contributor name. I can increase or decrease quantity, sort items, or remove an item. The order summary updates automatically.”

**1:20–1:45 | Collaboration and persistence**  
“I will open the same project in another browser tab. When I add or update an item in one tab, the other tab receives the update using browser storage events and BroadcastChannel. The cart remains saved when the page is refreshed.”

**1:45–2:05 | Activity log**  
“The activity page records important actions, including adding, updating and removing items, which improves transparency.”

**2:05–2:25 | Receipt**  
“The receipt page provides an itemized group summary. The Print or Save PDF option uses print styling to create a clean receipt.”

**2:25–2:40 | Closing**  
“CartShare brings a group’s shopping list, updates and estimated costs into one simple responsive interface. Thank you.”
